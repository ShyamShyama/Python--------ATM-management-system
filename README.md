# 🏦 ATM Management System (Python)

## 📌 Overview
<pre>
This is a menu-driven ATM Management System built using Python.

The project simulates basic banking operations such as account authentication, deposits, withdrawals, balance inquiries, transaction history tracking, and account security through PIN verification and account locking.

This project was created as **Project #3 in my Python learning journey towards AI/ML**, helping me strengthen my understanding of programming fundamentals, problem-solving, and structured code design.

</pre>

## 🚀 Features
<pre>
* 🔐 Secure PIN Authentication
* 🔒 Account Locking After 3 Failed Attempts
* 💸 Deposit Money
* 💵 Withdraw Money
* 💰 Balance Inquiry
* 📋 View Account Details
* 📜 Transaction History Tracking
* ↩️ Logout Functionality
* 🚪 Exit ATM System
* ⚠️ Exception Handling & Input Validation
</pre>

## 📂 Project Structure

### Account Database
<pre>
Each account stores:

* Account Holder Name
* PIN
* Balance
* Account Status (Locked/Unlocked)
* Mobile Number
* Transaction History
</pre>
### Core Functions
<pre>
* Deposit Money
* Withdraw Money
* Check Balance
* Show Account Details
* Show Transaction History
* ATM Menu Management
* Authentication System

</pre>

## 🔒 Security Features

### PIN Verification
<pre>
Users must enter the correct PIN to access their account.
</pre>
### Account Locking
<pre>
After 3 incorrect PIN attempts, the account is automatically locked.
</pre>
### Input Validation
<pre>
The system handles invalid inputs using exception handling to prevent crashes.

</pre>

## 📜 Transaction History
<pre>
Every successful deposit and withdrawal is recorded separately for each account.

Example:

💸 Deposited ₹5000

💵 Withdrawn ₹1000

💸 Deposited ₹2000

</pre>
